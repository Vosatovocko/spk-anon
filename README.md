# Speaker Anonymization

Research code for configurable speaker-anonymization pipelines and speech
evaluation. Pretrained model weights, speech datasets, and experiment outputs
are excluded; obtain and configure those resources separately under their
respective terms.

This project builds on
[DigitalPhonetics/speaker-anonymization](https://github.com/DigitalPhonetics/speaker-anonymization),
which is distributed under GPL-3.0. See `LICENSE` and the component-level
notices included with vendored dependencies.

## Setup

Install the Python dependencies with:

```sh
pip install -r requirements.txt
```

Configure dataset paths and download any required models separately before
running the preparation, anonymization, or evaluation scripts.
